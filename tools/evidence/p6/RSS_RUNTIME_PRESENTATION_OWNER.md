# RSS original lane and physical presentation ownership

The original RssOrchestrator owns its management mutationChain, latest confirmed/unknown receipt, readback and entity RssRouteOperationHost. `forRuntime` uses the existing Runtime identity and a native WeakMap to share that exact owner across Index reconstruction without statically pinning an otherwise unreachable closed Runtime. An obsolete/unavailable Runtime lookup cannot obtain or replace the current owner. The constructor stays compatible with existing controlled tests; Index integration must use the shared factory.

`attachPresentation(identity, emitList, currentManagement, emitOperation, emitRead, admitted)` requires a captured physical view admission before replacing delivery. The management route guard and mount/Runtime/navigation admission are distinct: other RSS routes share the lane without claiming management is visible. Changing identity retires queued original-session intents. `detachPresentation(identity)` affects only its exact attached view, never the newer view or original task tail/receipt. Old physical callbacks must be rejected before calling a fresh factory.

Accepted writes settle in the original owner, including a late ACK after view/Runtime retirement. UI lifetime only controls delivery and admission of subsequent reads. A same-Runtime replacement may receive the acknowledged write and canonical readback through its own admitted subscription. An unknown mutation survives warm remount and still allows only pure reconciliation: a matching row is not an operation receipt. Logger/delivery/admission exceptions cannot poison the serialized lane or rewrite a confirmed ACK.

The actual Gateway/full Orchestrator/Index/SDK management test covers same-Runtime replacement during an accepted write, original queued intent refusal, stale detach/attach, late ACK, retained unknown with read-only recovery, new/unavailable Runtime, throwing guard and throwing native delivery/logger. Existing editor, route, Runtime, persisted-refresh and page contract gates remain separate and pass after the changed real delivery-session guard is accounted for.

This leaf has no Index change and cannot close P2 until the actual factory, lifecycle detach and original physical callbacks consume it. Node/SDK emitted behavior does not prove complete ArkTS, native scheduling, GC timing, HAP or target behavior. A WeakMap is an ownership primitive, not proof of a memory budget. RSS lacks a cold durable caller-operation receipt contract; this warm cache neither creates one nor declares the gap an OS limitation. Hidden aggregate query/placeholder capabilities remain closed.
