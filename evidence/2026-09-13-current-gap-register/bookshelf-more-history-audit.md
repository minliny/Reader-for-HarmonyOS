## 阅读顶栏 More

当前 `LocalReadingExperience.ets:1741` 的 `onMore` 调用 `toggleCurrentPageBookmark()`，这是会修改书签的动作，不是 More 弹出菜单。用户20项第8（重复编号）只报告其无功能；已核对历史没有找到用户授权把 More 语义直接定义为书签开关。

因此可以说“当前回调非空，已接书签切换”，不能说“More产品功能已完成”。`CURRENT_GAP_REGISTER.md:132,147` 的 CODE FIXED 需保留产品语义未闭环说明。实施方案应明确 More 菜单与书签动作关系；不得继续把直接切换书签当既定最终设计。要使用当前可用业务能力拟定菜单时，应在主方案标为具体实施方案，而不是捏造成历史已确认。
