# 小说换源页面三套设计方案

用户要求梳理页面内容，再结合其他页面样式给出几个不同换源设计方案。之前把方案误画为同一页面的四个状态，本目录以三个独立页面布局回应该要求。

01、02、03 对应本轮聊天实际图片展示顺序，分别采用书架式书籍摘要与连续结果、章节对照清单、保留阅读背景的固定高度抽屉。三套共享纸色、深绿、宋体标题及同一组混合动态示例数据；信息主次、结果容器和阅读上下文占比不同。

内容：书名、作者、最新章节、当前书源；查找状态、已发现源数、停止或重新查找；每个候选的源名、最新章节、搜索耗时或待检测/失败状态、局部重试；点击行切换。当前源不重复作为候选。动态发现追加、字段就地补齐、重测保留和触摸/滚动延后重排均是后续实现必须满足的约束。

这是未获用户确认的自定义视觉稿，数据为虚构示例，不是应用截图或实测书源。这一轮未修改 Demo 或原生代码。静态图不构成动态交互或设备验收。选择方向后再细化停止/重测/切换忙与错误、长文本及其他尺寸。生成文字和封面仍有细节差异，见 manifest.json。
