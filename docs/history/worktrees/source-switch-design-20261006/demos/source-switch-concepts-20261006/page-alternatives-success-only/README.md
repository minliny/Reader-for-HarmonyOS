# 换源页面三方案：仅展示检查成功的书源

用户纠正：书源不存在检测失败，是有检查成功的书源才在列表中展示。此轮据此修正上一轮三个独立版式，01/02/03 对应本轮生成图片实际展示顺序。

页面摘要含书名、作者、最新章节、当前书源。候选列表是成功检查后的结果集合，每行只有源名、各源最新章节与搜索耗时，点行换源。检查过程在顶部表达查找中、成功源数量与停止或重新查找；成功结果逐条加入。候选中没有检查中、待检测、失败、超时、重试或占位项。

六条数据均为虚构成功结果示例，不是实测书源。三稿仍属未获确认的自定义视觉方案，本轮没有修改 Demo 或原生源码，未验证原生准入或动态交互。旧稿保留追溯，其候选展示逻辑已被本轮取代。细化缺口见 manifest.json。
