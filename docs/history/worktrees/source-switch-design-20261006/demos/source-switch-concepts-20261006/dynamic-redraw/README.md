# 小说换源动态状态重画

本轮为同一单列换源页面的四个连续状态稿：初次查找、增量补齐、保留结果重测、结束后的混合结果。01-03 对应聊天前三张；04 使用最后一张校正版（聊天第5张），替代带灰色圆环的初稿。

参照历史书架列表、搜索与书源管理页面的配色和字体。上方书籍摘要保留书名、作者、最新章节、当前书源；候选按固定两层信息排布，新条目追加，已知章节和耗时就地补齐；重测保留已有条目，失败支持局部重试。

本目录为未获用户确认的自定义视觉稿；图片数据为虚构样例，不是实测书源，也不构成实际动态交互、原生界面或设备验收。此轮没有修改 Demo 与原生源码。

图片仍有细节待细化：结束稿已去掉灰色活动圆环；四帧封面应统一同一真实资源，候选行的最新章节标识可继续明确。长文本、大字体、切换忙、停止状态、深色及其他尺寸未在此轮绘制。详见 manifest.json。
