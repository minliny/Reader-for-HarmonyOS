# 小说换源页设计内容

2026-10-06。01/02/03对应本次聊天中实际展示的三张设计稿顺序。图片为生成的视觉概念，书名、来源和耗时是示例；生成图片时未修改Demo实现；随后已将三版接入[HTML预览](../source-switch-density/app-baseline/index.html)，默认第一版，并在画布上方切换。尚未做浏览器或原生验收。

## 内容与信息优先级

| 区域 | 内容 |
|---|---|
| 书籍信息 | 小封面、书名、作者、最新章节、当前书源。参考书架列表，不把正在读替作最新章节。 |
| 候选结果 | 书源名称优先，候选自己的最新章节或等待解析次之；搜索耗时、探测与采集状态作为辅助。书名/作者存在差异时用于辨别。当前源不重复占候选行。 |
| 查找与导航 | 返回、重查；查找中允许停止并保留结果；已发现数量按不同sourceId统计。 |
| 切换与恢复 | 候选切换中、失败重试、结果未知时核对、事务需要时撤销；成功回阅读或目标详情。保留现有结果与书籍上下文。 |

搜索请求耗时不代表正文读取速度或书源成功率；首次发现可能没有章节，不能统一填相同最新章节。现有类型不提供评分、成功率、推荐依据或更新时间。

## 风格来源

三版均参考已归档的书架列表、搜索结果和书源管理设计图，沿用纸色、深绿、宋体标题、无衬线辅助文字、轻分隔线。归档图只用于设计语言，不作为当前原生运行截图。具体原图和生成图片的绑定见manifest.json。

图片覆盖主要候选状态。HTML另提供查找、停止、空结果、切换中、失败与结果未知的静态状态预览；不以这些状态宣称真实搜索或换源业务通过。
