# 选定第三套：小说换源完整流程

入口为本目录 index.html，默认停在阅读控制栏。原页面索引保存在 catalogue.html；本次没有改原生源码。

手动演示：

1. 点击控制栏右上角“换源”，纸色抽屉在 320 ms 内滑入，阅读正文保留在背景。
2. 成功源分批加入，初次查找约 6 秒结束。检查中与失败的源不进入列表；已出现的行保持 DOM 身份与位置。
3. 可随时点“停止”保留结果，再点“重新查找”；重查按 sourceId + bookUrl 更新，不重复追加。
4. 点选任意成功源，冻结发现与点选，抽屉收起并进入换源动画：准备目标书源 → 定位当前章节 → 恢复阅读。
5. 动画约 2.4 秒完成，更新当前书源及其最新章节，阅读仍停在“第三章 山路”的原展示位置。再次打开可看到新源，当前源不会重复作为目标。

画布外的“自动演示全过程”从控制栏开始，完整回放约 10 秒；“回到控制栏”可中断并重置。减少动画关闭位移和旋转，但不把异步检查或换源阶段伪装为同步成功。

读正文、控制栏和 SVG 图标复用现有 Reader demo；抽屉依照本轮第三张成功候选方案实现，封面采用内置 Image Gen 的单独资产。所有书源、章节与请求耗时均为示例数据，不执行网络、Core 写入或应用数据操作。

代码检查：`node build.mjs`、`node verify-source-flow.mjs`、`node verify-source-flow-ui.mjs`。构建产物为普通 IIFE 脚本，便于现有本地 file 页面使用。

检查记录见 source-flow-model-verification.json、source-flow-ui-verification.json、source-flow-evidence.json。浏览器工具曾明确限制本地 file 协议；本轮未用服务器、替换协议或其他浏览器规避。当前没有浏览器实际截图或动效实播证据，视觉 QA 仍为 blocked；静态模板与模型通过不代表浏览器、原生或设备验收。
