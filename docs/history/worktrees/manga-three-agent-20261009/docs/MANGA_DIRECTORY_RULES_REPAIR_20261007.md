## 问题与定位

斗破苍穹的数字分篇在来源规则添加 `✿·` 后被旧分类器当作正文标题。保留的官方 `ol.chapter-page-all` 语料共 681 条，来源装饰使 101（上）至 130（下）的 60 条分篇误入完整行；99、100 本身仍是免费章节。131 起的真实副标题仍应使用完整行。

同批审查还发现：缓存状态返回会丢展示元信息；旧目录快照可误用新版本事实；chapter 变量会保留前章 VIP/已购值；重复解析驻留窗口增加布局成本。上述问题均纳入本批实现。

## 实现契约

- 原始 title、index、URL、nodeId、层级、进度和下载身份保持不变。displayTitle/isVip/isPay/contextTitle 为独立可选事实。
- 来源装饰仅对确认的完整来源规则和版本薄适配。未知符号不在 Host 删除。旧缓存按当前来源和精确 TOC 摘要补齐事实。
- 事实绑定来源、目录、catalog/context 版本，刷新以现有事务及 CAS 发布。读取和状态返回再次检查快照。
- 两条目录路径、详情预览及当前章标题统一投影。搜索原文、展示名和完整父路径；搜索结果完整行。
- 简短编号、规范章序及上中下分篇采用有限紧凑布局，真实副标题保持完整行。仅超宽条目降级；不构造缺失章节，不改变点击目标。
- VIP 与已购独立，未知保持未知；下载缓存状态 cached 显示已保存。所有状态复用现有元信息样式并参加宽度预算。
- 导航使用有限布局 Map，每次实际投影变化计算一次。更新条件包含元信息、世代、窗口、宽度、字体、搜索与下载显示。
