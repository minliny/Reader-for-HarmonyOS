## 1. 页面与形态

### S-01 内容层级

阅读页 → 初始快捷页 → 二级快捷页。

二级页可以展开为对应完整态。完整态是同一内容的展开形态，不是额外业务页面。

### S-02 模块归属

- 目录与书签是目录模块内的两个标签，不是互相独立的控制栏，也不额外增加一级返回页面。
- 书签快捷态展开后仍为书签完整态，收回后仍为书签快捷态。
- 目录、书签、朗读、外观、设置、搜索、自动翻页、替换规则均受本文约束。
- 初始快捷页没有展开动作；不能从零散的完整组件推导出初始页完整态。

### S-03 重新打开

控制栏真正关闭完成后，再次打开进入初始快捷页。重置的是控制栏页面，不是阅读进度、设置或业务会话。

## 2. 统一动效语言

### M-01 独立组件、共同进度

同一个控制栏中的独立组件在同一进度下，沿各自轨迹移动、变形和显隐。

- 禁止用整页快速淡出／淡入替代组件变形。
- 禁止先让位、再展开的串行分段逻辑。
- 小横条的相对纵向位移进度对应整套组件的变形进度。
- 同类组件使用一致的相对运动规则；不同组件不必同方向、同距离。
- 展开和收回沿同一套路径正反运行；相同进度应产生相同画面。
- 拖动时位置直接跟手，不另加位置缓动造成滞后。

### M-02 各类组件规则

| 组件 | 快捷态展开为完整态 |
| --- | --- |
| 控制栏主体 | 底部保持锚定，顶部随小横条移动，主体高度同步变化 |
| 小横条 | 连续带动控制栏顶部；不新增本轮暂缓的按压视觉 |
| 上层需要展开的内容 | 跟随顶部移动，同时向两侧和下方展开 |
| 亮度条等需要让出的上层内容 | 保持自身高度，纵向跟随顶部，横向向右移动并淡出 |
| 底部模块导航 | 同步向下移动并淡出 |
| 完整态新增内容 | 随共同进度展开、显露，不等待其他内容退场后才出现 |
| 阅读器屏幕顶部信息栏 | 快捷／完整互变时保持稳定；只参与整个控制栏的打开与关闭 |

亮度条“跟随顶部、保持高度、向右淡出”是本轮在恢复基线之上确认的统一调整，不得声称所有旧 Figma 模块本来就完全一致。

列表通过窗口增高显露更多内容，不能把文字与整张列表拉伸放大。

### M-03 轨迹与自动播放分离

手指决定当前空间位置；松手后由自动驱动接续到目标。切换驱动不重建组件、不重置进度，不让各组件独立启动不同的时钟。

具体像素距离、裁切、层级、曲线和播放参数须来自设计提取与本轮明确调整的映射。本文不新增未经核对的毫秒数、位移量或按压效果。

### M-04 导入字体栏位（用户后续确认）

“导入字体”使用独立栏位，不与“系统字体”或其他字体入口重叠；默认排列在字体栏位的最末尾。

“默认最末尾”是初始或缺失顺序时的补全规则，不新增“永远锁定末尾”的限制；已有有效的用户自定义排序继续保留。它仍是完整外观内容中的导入入口，不新增快捷态导入入口，不改变整栏共同进度或另设让位时序。

此规则明确覆盖恢复稿中 Import `1691:20807` 与 System `1691:20799` 的重叠端点。原始 Figma 轨迹快照保留，不把调整后的格位冒称原稿坐标。

## 3. 完整生命周期

| 操作 | 结果 |
| --- | --- |
| 阅读页打开控制栏 | 初始快捷页 |
| 初始快捷页进入模块 | 当前模块的二级快捷页 |
| 二级快捷页点击小横条、上拖或上甩 | 当前内容的完整态 |
| 完整态点击小横条或收起入口 | 对应二级快捷页 |
| 快捷态下拉 | 关闭整个控制栏 |
| 完整态下拉 | 可以直接关闭整个控制栏 |
| 点击露出的阅读区域 | 关闭整个控制栏及控制栏所属临时层 |
| 章节、书签或搜索结果成功选择与跳转 | 关闭整个控制栏 |

### L-01 收回与直接关闭不是同一条过程

- 收回快捷态：亮度条、底部导航等快捷内容沿原轨迹恢复。
- 直接关闭：不能在途中突然恢复这些快捷内容。
- 完整态直接关闭不要求先停到快捷态，也不要求第二次下拉。
- 关闭命令可接管正在进行的其他动画，从当前画面连续衔接，不先补播到稳定端点。
- 不强制播放完整态 → 快捷二级页 → 初始页 → 阅读页的全部中间页面。

## 4. 点击、甩动和拖动

### G-01 点击

点击在松手时确认，不在按下时提前执行。

- 初始快捷页的小横条点击不展开。
- 二级快捷页点击小横条展开。
- 完整态点击小横条收回对应快捷页。
- 自动动画中短点改变当前过程目标，画面从当前状态接续。

### G-02 点按后甩动

一次按下—快速移动—松手是同一次触摸，不得先执行点击，再另行执行甩动。

- 手指仍在屏幕上，整个控制栏始终跟手，包括快速移动、停住、反向。
- 松手后才根据最近明确运动方向继续到目标。
- 速度影响衔接，不以是否越过半程或位移比例阈值决定终点。
- 不要求用户拖完整个移动轨迹。

### G-03 拖动

- 可以慢拖、停住、反向、再反向，所有组件仍取同一进度。
- 松手后按最近明确的拖动方向接续；微小手抖不应改写意图。
- 初始快捷页向上拖动／甩动不展开，向下关闭可用。
- 触点离开小横条范围后，已经开始的拖动继续有效。
- 第二根手指不抢占当前控制权。

### G-04 长按、暂停与重新接管

- 稳定状态下长按不动，不触发展开或收回。
- 自动动画中按住不动暂停在当前画面；长按后松手继续原目标。
- 按住后开始移动，切换为跟手拖动。
- 动画可反复重新抓住，不跳回起点或终点。
- 小横条变色、变粗、缩放等按压视觉反馈明确延期，不影响点击和拖动。

## 5. 返回和临时层

### B-01 稳定状态的系统返回

键盘、下拉菜单等临时层先处理，之后按以下顺序返回：

完整态 → 对应二级快捷页 → 初始快捷页 → 阅读页。

目录／书签标签不额外增加返回层级。

### B-02 动画中的系统返回

返回按操作顺序、来源与目标决定落点，不按动画是否过半决定。

- 打开、进入二级页或展开途中返回：撤销这次前进，回来源状态。
- 正在收回途中再次返回：继续后退一级，不必等待动画结束。
- 已在完整关闭途中返回：继续关闭，并消费这次返回，不穿透退出阅读器。
- 所有目标改变从当前画面接续，不跳帧、不排队补播中间页面。

### B-03 阅读区域点击

点击露出的阅读区域始终完整关闭，不等同于后退一级；同时关闭控制栏所属临时层。

## 6. 关闭完成、撤销与复位

### C-01 关闭提交条件

只有关闭意图仍然有效、画面到达关闭终点，并且没有正在持有的拖动手势，才算关闭完成并复位页面。

- 手指未松开，即使已经拖到完全不可见，仍能反向拖回，不能提前清空原状态。
- 松手时按已确认的最近明确方向规则确定后续目标，不能仅因几何位置到了终点就忽略反向意图。
- 无手势持有的自动关闭到达终点后，才提交关闭。

### C-02 撤销不算重新打开

- 关闭尚未完成时撤销，保留这一轮控制栏的模块、标签和形态上下文。
- 完整书签的关闭撤销不能跳成初始快捷页或目录标签。
- 自动关闭尚未结束，可以从当前画面重新接管。
- 真正关闭完成后重新打开，才进入初始快捷页。
- 系统命令接管后，旧手势、旧动画回调不得覆盖新目标。

### C-03 业务操作不回滚

撤销的是控制栏关闭，不回滚已成功生效的章节跳转、设置修改、朗读状态等业务操作。

## 7. 目录、书签和选择

### 2026-09-08 补充：朗读试验方案全局应用（用户批准）

- 范围：目录、书签、搜索、朗读、自动翻页、外观、设置、替换的快捷／完整互变；不修改 Figma 原稿。
- 自动展开 320ms，自动收起 260ms，直接关闭 200ms，未完成关闭的恢复 220ms；自动形变曲线为 `cubic-bezier(0.2, 0, 0, 1)`。初始页打开与模块导航不是展开，保留原独立语义和时序。
- 手指持有期间，整体变形直接跟随位移进度，不再套缓动；松手只运行剩余距离，并承接释放速度。所有组件共享同一进度，但各自保留原有位移、尺寸与图层轨迹。
- 收起接手时冻结真实滚动位置并停止惯性，不另开一段回顶动画；屏外共有组件的内容和轮廓都受可见区域裁剪，只在进入对应快捷位置时显露，不能穿过其他内容。
- 中段保留真实内容印象：公共淡化倍率最低 0.35、虚化最大 2vp；两端倍率 1、虚化 0。原本仅完整态出现的内容仍乘自身显露进度，原业务禁用透明度也保留；不把整个控制栏背景、亮度条与导航替换成淡入淡出页面。
- 外轮廓保持各自原有轨迹，普通设置页在完整收起且没有手指持有后才清除完整页滚动锚点；下一次新展开到顶部。动作中的反向和重抓保留当前轨迹。
- 目录／书签明确按原 D-01～D-04 执行：同一列表互变保留上下文，每次新打开按章节定位，不改成无条件回顶；选择、返回、关闭、输入保护及小横条按压反馈延期规则均不变。

### 2026-09-08 补充：滚动页收起与重新展开

- 朗读、自动翻页、外观、设置、替换、搜索：收起从当下实际滚动位置开始；完整收起后丢弃旧完整页滚动位置，下一次新展开到页面顶部。
- 收起不先回顶。快捷／完整共有组件从当前屏幕位置按同一进度变形至对应快捷组件；仅完整态存在的组件保留自身退出轨迹，不随共有组件整页回卷。
- 同一次未完成动作中的反向、重抓以及手指仍按住时触及端点，保留这次轨迹；不能把它当作“下一次新展开”重置。
- 搜索快捷态本身可滚动：从当前快捷结果位置连续展开至完整页顶部，不先跳到顶部；查询文字、结果身份和选择后关闭规则不改变。
- 滚动惯性在控制栏动效接手时以原位置停止。原生回调延迟只修正实际坐标，不覆盖已冻结的起点；收起完成后的回顶不可制造可见跳帧。
- 目录／书签按用户后续确认“目录按原规则”，保留 D-01～D-03 的章节定位与同列表上下文规则，不改为新展开回顶。
- 本条是用户确认的交互适配，不修改 Figma 原始组件尺寸、层级、局部轨迹或控制栏公共时钟。

### D-01 每次新打开定位

- 目录定位当前阅读章节，尽量处于列表窗口中心。
- 靠近首尾遵守真实滚动范围，不为了居中制造大量空白。
- 书签按书签章节与当前章节的序号差绝对值比较距离。
- 等距选阅读顺序靠前的书签，不按创建时间。
- 目标书签同样尽量位于列表窗口中心。

### D-02 定义新打开

重新进入／重新显示该列表触发本次定位。同一列表的快捷／完整互变、动画重抓、未完成关闭的撤销不是新打开，不重复定位。

### D-03 定位与显露同步

- 初始定位与列表显露衔接，不先出现错误位置再明显跳动。
- 用户开始滚动后，异步数据刷新不能反复把列表拉回当前章节。
- 加载中、空书签和目标暂不可用时显示相应状态，不伪造位置。
- 展开／收回时保留同一列表上下文，通过窗口变化显露内容，不替换成默认标签或重建为另一份列表。

### D-04 成功选择后关闭

章节、书签或搜索结果的目标准备和跳转成功后，关闭整个控制栏。失败时保留可操作界面，不先隐藏再留用户面对错误。

## 8. 手势归属和状态保护

### P-01 手势各司其职

- 小横条及明确拖动区域控制面板。
- 列表区域控制列表滚动。
- 亮度滑块控制亮度。
- 不默认采用列表滚到顶部后自动接管为面板关闭的规则。

### P-02 业务状态独立

展开／收回本身不重置模块、标签、输入和设置，不停止或重启朗读、自动翻页。

### P-03 中断与尺寸变化

- 系统取消、切后台、锁屏等不能被误判为点击、甩动或内容选择。
- 最新显式返回／关闭命令接管后，旧动画不得在结束时覆盖状态。
- 窗口尺寸变化保持画面和当前控制过程连续，不突然切到另一个端点。

### P-04 可访问性

- 为非触摸用户提供明确展开、收回、关闭入口。
- 初始快捷页不提供展开。
- 减弱动态效果只改变动效表现强度，不改变层级、关闭结果和列表定位。

## 9. 验收约束

必须分别验证交互逻辑、组件轨迹、实际触摸和实际画面。代码、测试、构建、安装成功均不能替代视觉符合性。

至少覆盖：

1. 初始快捷页点击／上拖／上甩均不展开，下拉可关闭。
2. 所有内容族的快捷／完整正反过程遵守相同组件语言。
3. 多个中间进度帧中，组件共同变形，没有先让位后展开。
4. 亮度条保持高度、纵向跟随顶部、向右淡出；导航同步向下淡出。
5. 慢拖、短甩、停住、反向、多次重抓均连续。
6. 完整态收回会恢复快捷内容；直接关闭不会中途恢复快捷内容。
7. 手指持有时拖至完全不可见再反拖，原模块／标签不丢失。
8. 关闭完成后重开初始页；关闭未完成的撤销不是重开。
9. 动画中单次／连续返回按操作顺序到达正确目标，关闭期间不穿透。
10. 目录居中和书签章节距离／等距规则正确，异步刷新不抢用户滚动。
11. 选择成功才关闭，失败可恢复；撤销关闭不回滚已成功跳转。
12. 列表、滑块不误控面板，临时层、第二指和系统取消不产生误动作。
13. 尺寸变化与减弱动态效果不改写交互规则。
