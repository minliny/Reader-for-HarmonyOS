## 1. 目标与非目标

### 1.1 唯一目标

在低端 HarmonyOS 真机上实现轻量、连续、可信的三维书页翻动：

- 首次可见位置来自真实触点，页面不从默认角度或固定角落突然出现。
- 手指未离开屏幕时，页边在合法约束内持续响应当前手指。
- 页面有真实厚度方向、正反面、遮挡和圆柱卷曲，不是平面裁剪、平移或镜像。
- 左侧装订边固定，纸张材料长度不变，不产生扇形拉伸。
- 快速翻页使用稳定速度；连续操作不截图、不重排正文、不重新建立 EGL 上下文。

### 1.2 明确不做

- 不做布料、弹性、压力、波纹、空气阻力或多折痕物理模拟。
- 不做透视相机、动态景深、实时模糊、多光源、法线贴图或纸张透光。
- 不做 Canvas/ArkUI/Native 多套仿真渲染器，也不提供二维平面仿真 fallback；系统“减少动态效果”和 DOWN 前能力自检失败可显式使用无动画换页 `none`。
- 不根据机型切换不同交互语义；机型差异只能影响不可感知的资源格式和预制调度。
- 不允许在手势中途因为纹理晚到而突然出现页体。

## 3. 坐标、页面角色与方向

### 3.1 坐标

- 所有手势规则在逻辑阅读视口的 `vp` 坐标中计算，左上角为 `(0,0)`，宽高为 `W,H`。
- 系统拥有的边缘和底部导航区域不属于逻辑阅读视口。
- ArkUI 与 Native 的坐标只在边界处按当前 surface 尺寸转换一次；同一指针流不得混用 `vp`、Canvas backing-store 像素和 PixelMap 像素。
- 第一根有效手指的 DOWN 保存 `P0=(x0,y0)`。当前有效样本为 `P=(x,y)`，累计位移为 `dx=x-x0`、`dy=y-y0`。
- 指针速度只用相邻两个有效平台样本及其时间戳计算，不做 EMA、低通或历史轨迹平滑。

### 3.2 页面角色

- 下一页：当前页是唯一运动页，从右向左卷走；下一页静止显示在下方。
- 上一页：上一页是唯一运动页，从左向右卷入并覆盖当前页；当前页静止。
- 纯纵向上滑触发上一页，沿用“上一页卷入覆盖当前页”的语义。
- 不能通过镜像当前页来伪造上一页。
- 任意时刻最多一张弯曲页体；控制层、选择菜单、会话胶囊和系统栏均不属于页体纹理。

### 3.3 水平方向锁定

- `dx<0` 锁定下一页，`dx>0` 锁定上一页。
- 方向一旦锁定，到第一根手指结束前不能切换。
- 手指反向越过 `P0` 时，页体最多回到平面；不能在同一指针流内转成相反方向翻页。
- 第一页向前、最后一页向后等无效方向完全无动效，也不建立待执行意图。

## 4. 手势判定合同

### 4.1 规范常量表

后文以 ID 引用本表；除第 11、12、13 节明确标为“工程初值”的项目外，不得在实现中复制另一套数值。

| ID | 含义 | 冻结值 |
| --- | --- | ---: |
| `I-X-SWIPE` | 点击与横滑分界 `X_MIN` | `8vp` |
| `I-LONG-TIME` | 长按时间 `T_LONG` | `500ms` |
| `I-LONG-SLOP` | 长按最大历史二维位移 `D_LONG` | `<8vp` |
| `I-PREV-Y` | 纯上滑上一页阈值 `Y_PREVIOUS` | `24vp` |
| `I-BOOKMARK-Y` | 下拉书签阈值 `Y_BOOKMARK` | `48vp` |
| `I-VERTICAL-X` | 纵向动作横向走廊 | `|dx|<8vp` |
| `I-EDGE-BAND` | 逻辑页边起点带 `D_EDGE` | `12vp` |
| `M-CATCH-FAST` | 内部起点快速追赶速度 | `5W/s` |
| `M-CATCH-NEAR` | 追赶速度匹配区 | `min(48vp,0.12W)` |
| `M-CATCH-LOCK` | 页边与触点锁定距离 | `4vp` |
| `G-AXIS-CAP` | 卷曲轴最左端 | `>=W/4` |
| `G-THETA-SOFT` | 倾角阻力起点 | `48deg` |
| `G-THETA-CAP` | 倾角硬极限 | `60deg` |
| `S-TILT-ZERO` | 结算倾角归零时间 | `80ms` |
| `S-END-RADIUS` | 完成时半径收敛末段 | 剩余 `12%W` |
| `B-RETURN` | 书签页面回弹时间 | `160ms` |

`I-LONG-TIME` 与 HarmonyOS 长按默认时间一致；自定义输入所有者仍使用 `vp` 的二维位移，不直接复用平台文档中的 `px` 位移值。

### 4.2 判定顺序

每个新指针样本按以下顺序判定：

1. 若满足 `I-X-SWIPE`，立即锁定水平翻页。
2. 否则若满足 `I-PREV-Y`，锁定纵向上一页。
3. 否则若满足 `I-BOOKMARK-Y`，锁定下拉书签。
4. 否则若满足 `I-LONG-TIME` 与 `I-LONG-SLOP`，交给文本长按选择。
5. 其余保持 tracking，完全无预览。

横移和纵移在同一帧越过阈值时，水平翻页优先。任何所有者一旦成立，本指针流不再进入其他动作计算。

### 4.3 点击

若第一根手指在 `I-LONG-TIME` 前结束、从 DOWN 起历史最大二维位移满足 `I-LONG-SLOP`，且没有触发纵向动作或其他控件，则按初始 `x0` 的 1:1:1 区域处理：

- 左三分之一：上一页。
- 中三分之一：打开控制层。
- 右三分之一：下一页。

点击翻页使用竖直页边 `theta=0` 和 `M-CATCH-FAST`，不根据点击 Y 制造斜角。未达到动作阈值的 MOVE 不显示临时翻页或书签预览。没有任何所有者成立、但历史最大二维位移已经达到 `I-LONG-SLOP` 的指针在 UP 时是 no-op，不能回落成点击。

### 4.4 长按

- 长按使用从 DOWN 起的历史最大欧氏位移 `max(sqrt(dx^2+dy^2))`，不是当前位移。
- 指针样本与 `I-LONG-TIME` 计时在同一时刻竞争时，先处理该时间戳对应的 MOVE；MOVE 越过横向或纵向阈值则动作优先，否则长按成立。
- 长按一旦成立，翻页、点击和书签均不得再次接管。

### 4.5 多指

- 每段交互只记录第一根手指的 pointer ID。
- 后续手指的 DOWN、MOVE、UP 全部忽略，不取消、不重置、也不改变方向。
- 第一根手指的 UP、应用可识别的离屏或丢失事件结束本段；其最后一个有效屏内坐标是结算输入。
- 平台系统 CANCEL 与普通离屏不同：CANCEL 只能回滚，不能提交翻页或书签。

## 5. 手指按住时的跟随合同

### 5.1 不允许的滞后

- 首个可见帧必须消费越过阈值的同一个实际 MOVE 样本。
- 每个 VSync 只消费最新有效样本；旧 MOVE 可以被合并，但最新样本不能排队等待历史样本播放。
- 不对触点、倾角或翻页进度做时间低通。
- 手指未结束时不得自动提交或自动恢复；唯一允许的自主运动是页边从来源边追赶静止或移动中的手指。

### 5.2 边缘起点

方向对应的来源边为：下一页 `x=W`，上一页 `x=0`。

- `P0` 位于 `I-EDGE-BAND` 时，越过启动阈值后的首个可见帧把运动页自由边直接放在当前手指 `x`；保持已锁方向时继续 1:1，反向进入恢复走廊时按第 5.3 节连续退回来源边。
- 该规则使用系统裁决后的逻辑阅读视口边缘；系统已接管的物理屏幕边缘不会启动页体。

### 5.3 内部起点追赶

内部触点成立后，页边从来源边向当前手指追赶：

设页边到手指沿当前翻页方向的距离为 `g`，手指当前有符号横向速度为 `v_f`：

```text
g > M-CATCH-NEAR:
    v_edge = M-CATCH-FAST

M-CATCH-LOCK < g <= M-CATCH-NEAR:
    k = g / M-CATCH-NEAR
    v_edge = v_f + k * (M-CATCH-FAST - v_f)

g <= M-CATCH-LOCK:
    edge_x = x_follow
```

上述速度在“从来源边向页面内部为正”的一维方向坐标中计算；目标反向时 `v_f` 可以为负。每帧把步长截到 `x_follow`，不得从任一方向越过目标。进入 `M-CATCH-LOCK` 后直接使用 `x_follow`，不保留弹簧、惯性或滤波尾巴。若手指在页边追上前结束，结果仍按原始指针相对位移判定，结算从页边当时的真实姿态继续。

方向锁定后定义 `dir=-1` 为下一页、`dir=+1` 为上一页，并定义只沿已锁方向增长的相对进度：

```text
h = max(0, dir*dx)
w_h = smoothstep(0, X_MIN, h)
x_follow = x_source + w_h*(x-x_source)
```

全文 `smoothstep(lo,hi,z)` 均指 `r=clamp((z-lo)/(hi-lo),0,1)`、返回 `r*r*(3-2*r)` 的无状态函数。

追赶控制器追的是 `x_follow`，不是未经约束的原始 `x`。因此首次越过 `I-X-SWIPE` 后按真实触点追赶；反向回到 `P0` 的恢复走廊中，目标连续退回来源边，`h=0` 时页体不会保留一个随后突现的隐藏卷曲姿态。

### 5.4 横向拖动的倾角

水平翻页锁定后，完整累计向量 `P0->P` 决定页边方向，不能使用最后一小段 MOVE，也不能在页面中线重选上下角。原始倾角固定为：

```text
theta_vector = atan2(-dir*dy, max(h, epsilon))
```

- 页边在页面平面内与 `P0->P` 垂直。
- `dy=0` 时页边始终竖直；例如从右上角水平移动，整段翻页均保持竖直页边。
- 横向进度保持不变而手指只上下移动时，翻页完成度保持，页边倾角按新的 `P0->P` 连续变化。
- 下一页与上一页使用镜像方向，但都必须选择从上到下连续的同一条页边切向，禁止符号跳变。

第 6.6 节完成极限阻力后，令 `s_edge=abs(g_x-x_source)`；最终可见倾角还必须乘两个连续门：

```text
theta = theta_limited
      * smoothstep(0, S1_ref, h)
      * smoothstep(0, S1_ref, s_edge)
```

其中 `S1_ref` 是第 6.4 节的初始掀起标尺。第一项是倾角的物理横向力臂：手势所有权仍在 `X_MIN` 成立，但仅移动 8vp 时不会把 1vp 的鼠标/触控纵向噪声放大成大角；第二项保证自由边刚离开来源边时不会整条边瞬间跳到大角。两项只约束几何可见幅度，不对触点样本做时间滤波，也不参与手势结果判定。

### 5.5 纯纵向上滑的倾角

纯上滑令 `U=y0-y`，满足 `I-PREV-Y` 时锁定上一页。上一页自由边从 `x=0` 追赶当前手指 `x`，虚拟参考点为左侧来源边上的 `G=(0,y0)`：

```text
L = max(x, 1vp)
theta_vector = atan2(U, L)
w_v = smoothstep(0, Y_PREVIOUS, U)
x_follow = w_v*x
```

- 此分支来源边为 `x_source=0`，第 5.3 节追赶控制器改为追 `x_follow`；达到阈值后它等于当前手指 X，反向回到原点时连续退回来源边。
- 手指停止后，页边只完成尚未结束的追赶；追上后姿态完全静止。
- 继续上移只改变倾角，不凭空增加横向指针位移。
- 后续横移继续更新页边目标和同一姿态，不新建第二段手势。
- 手指结束时仍满足 `I-PREV-Y` 则完成上一页，否则恢复。
- 可见倾角使用与水平分支相同的极限阻力和 `smoothstep(0,S1_ref,s_edge)` 掀起门；其意图门改为 `smoothstep(0,Y_PREVIOUS,U)`。所以纯纵移的首个可见帧只呈现与实际露出宽度匹配的斜角，不会突然生成一个完整斜边。

## 6. 三维纸张几何合同

### 6.1 唯一曲面

只使用一个可展的半圆柱卷曲曲面。页面材料坐标 `q=(u,v)`，其中 `u in [0,W]`、`v in [0,H]`、`u=0` 为左侧装订边。页边倾角为 `theta`，卷曲轴从上到下的切向和朝页面自由边的法向固定为：

```text
t = (sin(theta),  cos(theta))
n = (cos(theta), -sin(theta))
axis A = { q | dot(q,n) = a }
```

对任意材料点定义 `sigma=dot(q,t)`、`d=dot(q,n)-a`。半径为 `R`，`z` 是屏幕外深度方向：

```text
d <= 0:
    f_n(d,R) = d
    f_z(d,R) = 0

0 < d < pi*R:
    phi = d/R
    f_n(d,R) = R*sin(phi)
    f_z(d,R) = R*(1-cos(phi))

d >= pi*R:
    f_n(d,R) = -(d-pi*R)
    f_z(d,R) = 2R

p(q) = sigma*t + (a + f_n(d,R))*n + f_z(d,R)*z
```

该映射位置和一阶切向连续，沿材料法向的弧长保持 1:1。正面、卷曲带、背面、自由边曲线和背面边界必须全都采样这一个 `p(q)`；禁止为“边缘曲线”和“背面曲线”各建公式再裁剪拼接。

### 6.2 从触点到网格的唯一姿态求解

每个活动帧只有一条规范链路：

```text
最新平台样本
  -> 第 4 节输入所有权
  -> 第 5 节页边追赶目标 G
  -> 倾角 theta
  -> 材料抓取点 q_g
  -> 轴 a、卷曲量 d_g、半径 R
  -> 合法域投影
  -> p(q) 网格
```

不得从最终动画进度反推触点，也不得让 Renderer 再计算第二套姿态。具体求解固定如下：

1. `G=(g_x,g_y)` 是追赶控制器这一帧的实际自由边目标，不是原始 DOWN、最后一段 MOVE 或动画插值点。
2. 用第 5 节计算并门控后的 `theta` 建立 `t,n`。由于 `G-THETA-CAP`，`t_y=cos(theta)>=0.5`，不存在垂直分母翻转。
3. 抓取点始终位于材料自由边 `u=W`。先求 `v_star=(dot(G,t)-W*t_x)/t_y`，再令 `v_g=clamp(v_star,0,H)`、`q_g=(W,v_g)`。未触及上下边约束时，`dot(q_g,t)=dot(G,t)`，所以页边必定经过真实触点 Y，而不是吸附到固定角点。
4. 记 `Delta=dot(q_g,n)-dot(G,n)`。在未触发轴上限时先使用工程参考半径 `R_ref`，求唯一非负根：

```text
d_g - f_n(d_g,R_ref) = max(0, Delta)
a = dot(q_g,n) - d_g
```

`Delta=0` 时约定 `d_g=0`；`0<d_g<pi*R` 区间左侧函数单调递增，`d_g>=pi*R` 时等于 `2d_g-pi*R`，因此当前相位内不存在镜像根。

5. 倾斜轴在视口内的最左位置为：

```text
x_axis_min = (a + min(0, H*sin(theta))) / cos(theta)
```

若它违反 `G-AXIS-CAP`，固定 `x_axis_min=W/4`，由该等式反求 `a`，再由 `d_g=dot(q_g,n)-a` 在 `0<R<=R_ref` 内求使 `dot(p(q_g),n)=dot(G,n)` 的 `R`。这一步让轴停止左移，页边继续通过减小卷曲半径和展开背面追随触点。
6. 若 `v_star` 越过 `[0,H]`，或轴、曲线、自交约束使精确解不存在，只在当前方向和当前相位分支内求 `argmin ||p(q_g)-G||`。相等误差时依次选择与上一帧 `d_g`、`R`、`v_g` 变化最小的解；禁止跳到另一侧角点、对称倾角或另一卷曲分支。
7. 数值实现只允许有界解析式、查表或固定上限迭代；每帧输出一份不可变 `BookTurnPose`，Shader 与验收日志消费同一份参数。

页边进入 `M-CATCH-LOCK` 且第 5、6 步约束未激活时，`||p(q_g)-G||<=1vp`。约束激活后，误差必须等于到可行域的最短距离；指针继续向可行域外移动时误差非递减，姿态和一阶速度仍连续。该可测误差是“合法范围内始终跟手”的判据。

下一页使用当前页，按 `G: W->0` 运行上述轨迹。上一页使用上一页纹理，按 `G: 0->W` 沿同一组姿态反向展开：它是下一页“当前页卷走”轨迹的严格时间反向，并交换正反面朝向和遮挡次序，不做屏幕镜像，也不变形当前页。纯纵向上一页复用这一反向轨迹。

### 6.3 UV、投影与材料约束

- `UV=(u/W,v/H)` 永远来自材料坐标，不能按屏幕投影重新生成。
- 使用正交投影；Z 只参与遮挡、正反面和明暗，不通过透视除法缩放正文。
- `G-AXIS-CAP` 使轴在整条 `u=0` 右侧，故装订边处于 `d<=0` 平面段；所有装订顶点必须满足 `p(0,v)=(0,v,0)`，屏幕误差 `<=0.5px`。
- 相邻材料边长度误差 `p95<=0.5%`，任何采样点不得超过 `1%`。

### 6.4 掀起、翻转与滚动

拖动与普通结算中 `R>0`，三段按抓取点的实际材料卷曲角 `phi_grip=clamp(d_g/R,0,pi)` 定义，不按手指横移距离分段；最终原子交换帧的 `R=0` 使用极限姿态，不再计算该比值：

- `0<phi_grip<pi/2`：掀起，材料从平面连续卷到 `90deg`。
- `pi/2<=phi_grip<pi`：翻转，材料连续越过页边到 `180deg`。
- `phi_grip=pi` 且仍有背面展开：保持半圆柱截面并向装订侧滚动。

初始工程半径为 `R_ref=clamp(0.057W,18vp,32vp)`；对应材料里程碑 `S1_ref=pi*R_ref/2`、`S2_ref=pi*R_ref` 只用于阶段 1 探针和倾角露出门的初始标定，不是手势阈值，也不是由手指横移直接代入曲面的行程。三段是同一公式的连续区间，不是三套状态或渲染器；恢复严格沿已经走过的姿态反向运行。

### 6.5 左侧装订轴、曲线极限与触点投影

- 左侧装订边 `u=0` 永远固定。
- 跟手阶段，倾斜卷曲轴整条可见线段的最左端满足 `G-AXIS-CAP`；约束的是整条轴，不是轴中心。
- 达到上限后，额外合法横移按第 6.2 节改变 `R` 和背面展开量，轴不得继续左移。
- 自由边、背面边界和卷曲轴不得相交、反序或穿过 `x=0`。
- 两条可见曲线必须由同一 `BookTurnPose` 采样；不得分别限幅、分别吸附或分别拟合触点。

约束优先级固定为：

1. 装订边固定。
2. 纸张材料不伸缩。
3. 轴、自由边和背面曲线不越界、不相交。
4. 保持已锁方向、相位分支和时间连续。
5. 在前四项成立的可行域内最接近当前触点。

### 6.6 倾角极限与连续性

```text
theta_limit = min(G-THETA-CAP, axis_limit, curve_limit)
theta_soft = min(G-THETA-SOFT, 0.8*theta_limit)
```

`axis_limit` 和 `curve_limit` 不是另两个人工角度。新手势首帧从 `theta=0` 所在分支开始；后续每帧先把上一帧 `theta` 代入当前触点重算，再沿它到 `theta_vector` 的最短角路径检查合法性。自由边刚触及边界时，选择离上一分支最近的边界根，不得每帧重新从 0 搜索并跳到另一个对称根；上一分支在当前输入下短暂越界时，先在其两侧选择最近合法锚点，再沿当前目标方向细化。该规则同时禁止跨越非法区瞬移到远端“可行”姿态，也禁止把已连续进入的远端相位突然拉回零角分支。

原始角绝对值不超过 `theta_soft` 时令 `theta_limited=theta_vector`。超过后使用连续阻力：

```text
m = abs(theta_vector)
b = theta_limit - theta_soft
theta_abs = theta_soft + b*(m-theta_soft)/(m-theta_soft+b)
theta_limited = sign(theta_vector)*theta_abs
```

再应用第 5 节的意图与页边露出门。角度硬上限的阻力函数在起点位置连续、一阶斜率为 1，并渐近 `theta_limit`；曲线/装订边约束则沿上一段合法姿态投影到最近边界。整个指针流始终沿上一帧相同相位分支求解；手指经过垂直方向或只移动少量像素时，不允许切到看似更近的对称解。跟手阶段卷曲半径下限为 `0.35*R_ref`；结算时该下限随 `radiusScale` 连续降到 0，不能在跟手中突然塌成二维反射平面。

## 7. 松手、离屏、完成与恢复

### 7.1 结果判定

不用速度、页面比例或第二提交阈值，只看第一根手指最后有效相对位置：

- 下一页水平手势：最后位置仍满足已锁方向的 `I-X-SWIPE` 则完成，否则恢复。
- 上一页水平手势：最后位置仍满足已锁方向的 `I-X-SWIPE` 则完成，否则恢复。
- 纵向上一页：最后位置仍满足 `I-PREV-Y` 则完成，否则恢复。
- 系统 CANCEL：始终恢复。

只要水平手势最终仍满足 `I-X-SWIPE`，轻拨后立即离屏也属于翻页。若先超过阈值又反向回到阈值内，则恢复。

### 7.2 结算运动

- 完成和恢复都从当前真实曲面继续，横向自由边速度保持 `M-CATCH-FAST`。
- 结算开始后，页边倾角按 `S-TILT-ZERO` 连续归零；横向速度不能因归零暂停、减速或反弹。
- 完成进入 `S-END-RADIUS` 后，卷曲半径连续收敛到 0；卷曲轴仍遵守 `G-AXIS-CAP`。
- 恢复沿相反方向回到来源边和平面姿态。
- 不使用 spring、overshoot、bounce 或固定等待。

### 7.3 原子换页

- 自由边到达终点、倾角为 0、半径为 0 的同一个 VSync，完成页索引、静态底页槽和运动页隐藏的原子交换。
- 不允许出现一帧平面旧页、空白页或错误页，再在下一帧换内容。
- Renderer 不直接提交阅读业务；它只报告结算终点。现有页面事务确认后，呈现会话才执行原子纹理槽交换。
- 若业务确认晚于视觉结算，保持终点完全覆盖帧，不显示中间 fallback；失败则从终点姿态快速恢复并显示错误。
- 阅读进度持久化不得发生在 MOVE 或绘制热路径。

## 8. 下拉书签合同

下拉书签仅在满足 `I-VERTICAL-X` 和 `I-BOOKMARK-Y` 时获得所有权。获得所有权后，在书签流程结束前不运行翻页计算。

```text
D_current = max(0, y-y0)
D_peak = max(D_peak, D_current)
page_offset_y = clamp(D_current/2, 0, H/2)
preview_toggled = D_current >= D_peak/2
```

- 初次达到 `I-BOOKMARK-Y` 时预览状态翻转：原本有书签则预览移除，原本无则预览添加。
- 手指继续下拉时，正文整体以手指一半速度移动；最多移动到 `H/2`。
- 手指反向回到本段峰值的一半以下，预览恢复原状态；再次超过一半则重新显示翻转状态。
- 第一根手指结束时，以最后坐标和 `D_peak/2` 判断最终状态；随后正文按 `B-RETURN` ease-out 回到原位。
- 回弹期间不进入翻页、点击或长按，也不使用弹簧。

## 9. 输入所有权与冲突合同

### 9.1 DOWN 前的优先级

1. HarmonyOS 系统返回、主页和多任务手势区域。
2. 已显示的弹层、按钮、控制栏、会话胶囊、文本选择句柄和无障碍操作。
3. 正文区域的统一阅读输入所有者。

系统手势区域取平台实际裁决结果或运行时 inset，不由仿真模块强占。应用未收到完整指针流时完全不显示页体。

### 9.2 获得所有权后

- 水平翻页、纵向上一页或书签一旦锁定，阅读操作层拥有逻辑视口内整条第一指针流。
- 后出现的控制层、胶囊状态变化、TTS 高亮和 Auto Page 到期不能抢走该流。
- 胶囊保持可见，但类型、位置、尺寸和点击能力冻结到本段交互及其结算结束；数据更新延迟提交布局。
- 文本选择成立后，页体模块完全退出；不能先显示卷页再弹出选择菜单。

### 9.3 返回和生命周期

- tracking 或 dragging 收到系统 CANCEL、页面退出、旋转或阅读视口重建：不提交业务，立即回滚或随页面销毁隐藏。
- commit 结算尚未到原子提交点时收到退出：取消业务提交并隐藏，不留下半提交页码。
- 已越过原子提交点后收到退出：保留已提交页码，不再反向修改。
- 物理返回、侧滑返回和应用内返回走同一个协调入口。

## 10. 完成期间的新触摸与自动翻页

### 10.1 一个待处理段

- commit/rollback 结算不能被新触摸打断，也不能 regrab 当前网格。
- 结算期间只记录最先到达的一个新第一指针段；该槽一旦占用，后续 DOWN 和后续已经结束的完整意图全部忽略，禁止覆盖。
- 若结算完成时该手指仍按住，以完成时的当前坐标作为新的 `P0`，此前位移清零，从下一样本开始正常跟随。
- 若该手指已经结束，只保留这一段最终解析出的一个点击或翻页意图；上一段完成后以竖直页边执行。未完成判定的噪声、长按和书签预览不延迟重放。
- 待处理槽在第二段开始或被判定无效后才清空；语义固定为 first-pending-wins，没有 latest-wins、同类覆盖或无界队列。

### 10.2 点击、Auto Page、TTS 与音量键

- 所有非手指拖动翻页统一使用 `theta=0`、`M-CATCH-FAST` 和同一圆柱曲面。
- 全局只有一个 deferred-turn 槽：第 10.1 节尚未结束的 pending 指针段优先占槽；槽为空时 Auto Page/TTS/音量键才可记录最先到达的一个事件，后到事件忽略且不轮询重试。
- 人工 DOWN 到达时先取消尚未执行的自动事件；自动事件只在输入、结算、控制层和胶囊均为空闲且纹理就绪后触发。
- 自动翻页不能打断手动动作，也不能在无效页面边界播放空动画。

## 11. 纸张与光影标定边界

产品冻结的是“有正反面、厚度方向、自遮挡、折痕和投影，且不能压过正文可读性”；下表是阶段 2 的统一初始探针值，可在同一设备和同一轨迹 A/B 证据下整体标定，不是新的产品待决项。

| 效果 | 工程初值 |
| --- | --- |
| 正面 | 原页面纹理，亮度与饱和度不改 |
| 背面纸色 | 从当前正面纹理派生：亮度 `96%`、去饱和 `10%`；禁止替换成固定米黄/灰色 |
| 背面镜像字迹 | 与同一材料 UV 一起翻转，不建立独立位图或离散三角面着色分支 |
| 页面投影 | 最大 alpha `0.22`；宽 `clamp(0.06W,18vp,36vp)` |
| 折痕暗带 | 最大 alpha `0.12`；宽 `clamp(0.035W,12vp,24vp)` |
| 折痕高光 | 最大 alpha `0.04`；宽 `clamp(0.02W,8vp,16vp)` |
| 页体透明度 | `1.0` |

- 正反面明暗由同一圆柱法线和固定方向光计算；环境项初值 `0.94`、漫反射最大增量初值 `0.06`、镜面反射为 0。正反面过渡只由连续 `phi` 决定，禁止使用 `gl_FrontFacing` 形成逐三角形色块。
- 投影、暗带和高光只允许一维解析渐变或小型常量 LUT。
- 不使用实时 blur、离屏 FBO、多 pass 光照、动态噪声、半透明纸张或正文重采样。
- 浅色、深色和自定义背景只改变颜色基底，不改变几何和手势参数。所有主题必须共用一组完成标定后的光影数值，不允许按机型或页面动态切换。

## 12. 唯一实现架构

采用一个 `XComponentType.TEXTURE + OpenGL ES 3.0` 渲染面，在 ArkUI 正常合成层级内绘制固定低多边形三维页体。Legado 式页面预制和事件驱动保留，Canvas 反射不保留。

```text
分页 PageModel
   +--> 现有页面准备/事务/持久化 --------------------------+
   +--> BookTurnTextureBuilder --> TextureWindow           |
                                                            v
Raw Touch --> ReaderPageInteractionLayer --> shared Input Arena
                                              |
                                      page owner acquired
                                              v
                                      BookTurnMotionState
                                              |
                                  BookTurnPresentationSession
                                      | latest input mailbox
                                      v
                                    Native Solver
                                      | one BookTurnPose
                                      v
                               XComponent TEXTURE / GLES3
```

这里的 `shared Input Arena` 是点击、长按、书签、翻页、控件和系统裁决共享的唯一原始输入状态，不是仿真专属的第二 reducer。页面准备、业务提交、进度持久化和 pending 业务事件继续只有现有一套所有者；呈现会话不能复制这些职责。

### 12.1 ArkTS 职责

- `ReaderPageGestureState.ts`：在现有文件上收敛为 shared Input Arena，统一处理第一指针、阈值竞争、动作所有权和最终意图；仿真不得另建原始手势 reducer。
- `BookTurnMotionState.ts`：只有 page owner 成立后才创建，保存第 5、7 节所需的 `P0`、最新样本和追赶状态，只产出最新 `BookTurnInput`；不重复 Native 几何、不决定页码、不持久化。
- `BookTurnPresentationSession.ets`：只协调纹理就绪、Native 呈现、结算终点和原子槽交换；不拥有第二页面事务、第二 pending 队列或业务重试器。
- `BookTurnTextureBuilder.ets`：在 idle 异步生成物理页 PixelMap，不参与 MOVE。
- `ReaderBookTurnSurface.ets`：只承载 XComponent、surface 生命周期和极少量 Native 调用。
- 现有 `ReaderPageInteractionLayer.ets` 仍是唯一全屏输入层；不得再叠加第二个仿真手势层。
- `LocalReadingExperience.ets` 继续唯一拥有相邻页准备、页面事务、提交/失败、进度持久化和一个 pending 业务事件；它只向呈现会话提供 PageModel 并接收终点，不内嵌几何公式。

### 12.2 Native 职责

新建独立的 `entry/src/main/cpp/bookturn/`，不恢复旧 `pagecurl/`：

- `bookturn_solver`：实现第 6 节的纯数学、合法姿态投影和性质测试。
- `bookturn_renderer`：持久 EGL context、固定 shader、纹理槽、固定网格和三次以内 draw。
- `bookturn_host`：XComponent 生命周期、最新姿态邮箱、按需帧注册和原子槽交换。
- `bookturn_napi`：只暴露初始化、纹理上传、最新输入样本更新、结算和释放；MOVE 到 Native 的调用只传复用缓冲或定长标量，不创建结果对象、不返回大数据。

### 12.3 单一 Renderer 的预算边界

- 视觉复测已否决 `25x17` 探针网格。统一固定为 `65x129=8,385` 个顶点、`64x128x2=16,384` 个三角形；该成本远小于全屏纹理片元采样，并消除倾斜自由边每 1/16 页高一个折角的问题。不能运行时按机型切网格。
- 每帧由 vertex shader 根据轴、半径和角度 uniform 计算位置，CPU 不重建网格。
- 产品运行态最多 3 个 draw：静态底页、双面运动页、解析阴影。
- 使用正交投影；仅为页体自遮挡启用深度，关闭 MSAA、FBO 和 blur。
- EGL context、program、uniform location、VBO/IBO 和纹理对象在阅读会话内复用。
- idle 时注销帧回调；tracking 未越阈值且无视觉、dragging 和 settling 之外不连续刷新。

### 12.4 纹理窗口

- GPU 槽固定为 `previous/current/next/staging`，提交时交换句柄，不复制纹理。
- 正文、页内图片和静态页眉页脚属于页面纹理；会话胶囊、控制层、选择层和动态 TTS/Auto Page 高亮不进入运动页纹理。
- 页面时钟或胶囊更新不得使正文纹理失效；拖动和不超过一次结算期间允许冻结动态 chrome。
- PixelMap 创建、像素转换和上传只能发生在 idle/preparation；MOVE、绘制和结算热路径禁止截图、分页、图片解码和全页内存复制。
- 阶段 2/3 先探针不透明 `RGB565`；若棋盘格、正文抗锯齿和 EPUB 图片视觉门禁不通过，整体选择 `RGB8`。格式在开放设置前固定为全局单一结果，不能运行时混用或降级。
- 初始预算探针：四槽总 GPU 页面纹理 `RGB565<=24MiB`、`RGB8<=36MiB`，单页像素数 `<=3,000,000`；最终门槛以指定低端机实际分辨率和进程预算记录为准，但不得靠 MOVE 热路径重建纹理降低常驻量。

### 12.5 无手势中途 fallback，DOWN 前显式降级

- 阅读会话进入、视口重建和设置切换时先完成 Renderer 能力与相邻纹理 readiness 检查；同一指针流的渲染路径在 DOWN 前确定，MOVE 后绝不切换 Renderer 或从无动效突然挂上一张页体。
- Native surface 或 shader 能力自检失败时，仿真设置显示不可用，本会话显式使用无动画换页 `none`；不能暗中切到 cover、slide、Canvas 折页或静态截图动画。
- 系统“减少动态效果”开启时，无条件使用 `none` 并立即执行同一页面事务；关闭后须重新通过 readiness 才恢复仿真。
- 相邻纹理在 DOWN 前未就绪时，shared Input Arena 不授予 page owner、不提交页码，返回可观测的 `PAGE_PREPARING` 状态并继续异步准备；中心区控制层和已有控件仍可正常响应。不得静默吞掉页面意图，也不得显示平面临时效果。
- 获得 page owner 后 Renderer 失效时按系统 CANCEL 回滚，标记仿真不可用并在下一段按上述 DOWN 前规则处理；失败帧不能提交页码。

## 13. 性能结果门槛与工程探针

阶段 0 必须从产品最低支持范围中指定至少一台量产低端物理机，记录精确型号、SoC、GPU、RAM、系统版本、分辨率和刷新率。设备未命名、Profiler 采样方法未固定之前，性能状态只能是 `OPEN`；旗舰机、模拟器和 VM 不能替代低端门槛。

### 13.1 热路径

- 首个可见反馈：越过阈值后的 `1` 个 VSync 内；这是产品结果门槛。
- 60Hz 活动帧总耗时：`p95<=16.7ms`、`p99<=20ms`，连续 100 次翻页不得出现 `>33ms` 活动帧。
- 触点到送显：`p95<=25ms`、`p99<=33ms`。
- 初始归因预算：MOVE ArkTS `p95<=0.8ms`、Native 求解与邮箱写入 `p95<=0.25ms`、活动帧 CPU 提交 `p95<=2ms`、GPU `p95<=4ms`。这些是阶段 2 的诊断初值，可在不突破总帧和触点到送显门槛时重新分配，不能据此新增线程、Renderer 或业务状态机。

### 13.2 资源与吞吐

- MOVE 应用热路径不新增数组、对象、Promise、PixelMap 或全页 buffer；平台已经交付的事件对象不计为应用分配。
- 页面纹理常驻满足第 12.4 节最终实测预算；单页准备期间额外峰值内存初始目标 `<=24MiB`，阶段 3 必须记录分配器开销、上传双份驻留和回落后的稳定值，再冻结设备门槛。
- 空闲功耗：仿真 Renderer 无持续帧回调、无轮询重试。
- 程序化完整页按 `M-CATCH-FAST` 的名义结算约 `200ms`，感知目标为突发 `5` 页/秒；指定低端机连续 100 页的可验收下限为平均 `>=4.5` 页/秒、相邻原子交换间隔 `p95<=225ms`，同时满足帧时间门槛。
- 快速操作期间允许且只允许一个 pending 段，不得建立无界页队列。

任一低端门槛未通过，先减少纹理峰值、同步工作和 draw 成本；不得通过降低跟手、增加滤波或替换成平面效果换取通过。

## 14. 开发实施方案

### 阶段 0：清洁基线

1. 完成旧 PageCurl Native、Canvas 仿真、旧 NOTICE、旧测试合同和设置入口的删除。
2. 保留非仿真的 `none/slide/cover/scroll` 现有行为，建立“仿真不可用”的干净基线。
3. 跑完 HarmonyOS 非服务型契约和 HAP 类型检查，记录 HEAD、dirty paths 和测试结果；同时指定第 13 节低端验收机与采样方法。

停止条件：仍能搜索到旧 `pagecurl` Native 符号、旧二维仿真 fallback 或旧视觉阈值时，不进入阶段 1。

### 阶段 1：纯几何探针

1. 只实现 `bookturn_solver` 和棋盘格轨迹回放，不接正文、不接设置页。
2. 覆盖水平、斜向、半程纯纵移、纯上滑、反向恢复、零横移倾角门、上一页严格反向变换和 `G-AXIS-CAP`。
3. 自动检查装订边、材料长度、触点误差、唯一根/相位连续、轴/曲线合法性和角度连续性。

停止条件：任一轨迹存在轴漂移、长度误差、对称角跳变、多个未裁决姿态根、非法触点误差或独立曲线裁剪，不进入 Renderer。

### 阶段 2：单一 Renderer 探针

1. 建立 XComponent TEXTURE、持久 EGL、固定网格和第 11 节光影。
2. 使用脚本化指针轨迹和棋盘格正反面验证真实三维、遮挡、UV 和起点。
3. 在低端真机记录 CPU/GPU/帧时间；确定全局统一的 RGB565 或 RGB8，不做机中动态切换。

停止条件：视觉仍像二维折片、低端门槛失败或需要第二渲染器才能掩盖问题时，退回阶段 1 评审。

### 阶段 3：页面纹理窗口

1. 接入 previous/current/next/staging 四槽和异步页面快照。
2. 证明 dragging/settling 期间截图次数、分页次数和正文重排次数均为 0。
3. 验证 TXT、EPUB、正文图片、浅色、深色及自定义背景。

停止条件：首帧需要同步截图、纹理晚到附着、内容空白或峰值内存超标，不进入产品输入。

### 阶段 4：统一输入与书签

1. 在现有唯一 `ReaderPageInteractionLayer` 和 `ReaderPageGestureState` 上收敛 shared Input Arena；只在 page owner 成立后创建 `BookTurnMotionState`。
2. 实现第 4、5、8、9、10 节全部动作和所有权，不创建第二全屏手势层。
3. 用记录的 pointer ID、坐标、时间戳回放所有轨迹，禁止只测最终方向。

停止条件：触发前有预览、纵移撤销已锁定横翻、第二指取消、胶囊抢流或系统 CANCEL 提交时，不进入页面事务。

### 阶段 5：页面事务与原子交换

1. 复用现有分页 PageModel、相邻页准备、业务提交、持久化和 pending 所有者，只新增 presentation session。
2. 接入下一页当前页卷走、上一页上一页覆盖、失败恢复和原子纹理槽交换。
3. 接入点击、Auto Page、TTS、音量键及一个 pending 段，不使用轮询。

停止条件：动画终点与逻辑页码不同帧、持久化阻塞 MOVE、快速翻页丢失当前页身份或出现 flat fallback 时，不开放设置。

### 阶段 6：设置开放与物理设备验收

1. 前五阶段全部通过后，才把 `simulation` 重新加入翻页设置。
2. 生成干净无增量 HAP，记录源码 HEAD/dirty、HAP SHA-256、生成时间和内嵌 Native 身份。
3. Phone 与 Tablet 分别执行功能轨迹；低端物理机执行完整性能矩阵。
4. 用户完成视觉验收前，状态只能是 `IMPLEMENTED/DEVICE-VERIFIED`，不能写 `ACCEPTED`。

## 15. 自动化与验收矩阵

### 15.1 纯状态测试

1. `I-X-SWIPE` 前无视觉；达到后水平优先并锁方向。
2. `I-PREV-Y`、`I-BOOKMARK-Y` 及同帧竞争。
3. `I-LONG-TIME/I-LONG-SLOP` 边界和平台时间戳相等时的判定顺序。
4. 第一指完整生命周期；第二指全程忽略。
5. 越阈后反向到阈值内恢复；最终仍越阈完成；不使用速度提交。
6. 第一页/最后一页无动效。
7. 无 owner 但二维位移越过 tap slop 的 UP 为 no-op。
8. 结算期间仍按住、结算期间已抬起、多次 pending 的 first-wins 一段上限。

### 15.2 几何性质测试

1. 所有 `v` 上 `u=0` 误差 `<=0.5px`。
2. 棋盘格边长误差满足第 6.3 节。
3. 轴最左端始终满足 `G-AXIS-CAP`；自由边和背面曲线无相交、反序和越界。
4. `theta` 在零横移、中线、极限角和纯纵移处连续，不出现对称解跳变或隐藏姿态重现。
5. 页面前后面 UV 连续，正文不产生梯形或扇形伸缩。
6. `phi_grip=pi/2` 与 `pi` 两个里程碑前后位置和一阶变化连续。
7. `G->q_g->a,d_g,R->p(q)` 每帧只有一个合法结果；上一页相同轨迹与下一页时间反向逐点一致。
8. lock 且未受约束时触点误差 `<=1vp`；约束外推时误差非递减、姿态不换分支。

### 15.3 实机轨迹

1. 右侧上/中/下边缘水平下一页，首帧页边与手指一致且保持竖直。
2. 左侧与右侧内部起点，页边先按 `M-CATCH-FAST` 追赶、近区匹配速度、进入 `M-CATCH-LOCK` 后锁定。
3. 页边追上前快速离屏，分别完成和恢复。
4. 翻到 25%、50%、75% 后只上下移动；横向进度保持，倾角连续。
5. 斜拖经过垂直方向后再移动 2-5px；不得跳为镜像角。
6. 极端纵移命中角度和四分之三轴限制；两条曲线仍来自同一姿态。
7. 纯上滑上一页、停止、继续、反向、横移及松手。
8. 下拉书签到阈值、到峰值、回到半峰以下、再次下拉、松手回弹。
9. 点击 1:1:1、长按选择、控制层、胶囊、系统返回、底部主页和系统 CANCEL。
10. 第二指在各阶段加入；第一指继续正常工作。
11. 完成期间第二段仍按住和提前抬起；只执行第一个 pending 段，后续不得覆盖。
12. 点击、Auto Page、TTS、音量键均为竖直页边。
13. 连续同向 100 页、交替方向 100 页，记录帧时间、内存和纹理准备。
14. readiness 缺页、Renderer 初始化失败、运行中失效和系统“减少动态效果”；只允许 DOWN 前显式 `none` 或 CANCEL，不出现平面 fallback。
15. TXT、EPUB 正文图片、浅色、深色、自定义背景、Phone、Tablet 和旋转重建。

### 15.4 证据要求

每次设备验收必须归档：

- Git HEAD 与精确 dirty paths。
- HAP 绝对路径、SHA-256、字节数和生成时间。
- 设备型号、系统版本、刷新率和内存级别。
- 原始触点坐标/时间戳、屏幕录制和关键帧截图。
- CPU、GPU、帧时间、触点到送显、内存峰值和纹理准备计数。
- 每个场景的 PASS/FAIL，不得用成功构建或静态测试代替设备和用户验收。

## 16. 变更控制

- 本合同没有待用户决定项。
- 第 4.1 节规范常量、页面角色、唯一姿态链路、`G-AXIS-CAP`、first-pending-wins、DOWN 后不切 Renderer、触点误差和安全降级语义均为产品冻结项，工程侧不得静默调整。
- `R_ref`、网格密度、纹理格式、光影初值、纹理/临时内存探针和内部 CPU/GPU 子预算属于工程标定项；只能在阶段门内调整，并必须用同一轨迹和同一指定低端设备提供 before/after。调整不得改变触发、跟手、曲面、结算结果、总帧门槛或架构所有权。
- 任一实现如果需要恢复旧 PageCurl 文件、第二渲染器、第二原始手势 reducer、第二页面事务/队列、触点滤波、纵移取消、平面 fallback 或不同页面语义，必须停止开发并重新评审，不能继续补丁叠加。
