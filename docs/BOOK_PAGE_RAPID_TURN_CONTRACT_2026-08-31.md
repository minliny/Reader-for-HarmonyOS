# 全模式快速翻页合同（2026-08-31）

## 1. 适用范围

适用于仿真、覆盖、滑动、无动画和滚动五种阅读翻页模式，也适用于点击、已提交的拖动手势和音量键产生的手动方向请求。滚动模式沿用左侧上一屏、中间控制层、右侧下一屏的点击分区，垂直拖动仍归 List 滚动所有。自动翻页保留独立会话状态，不计入手动快速翻页目标。

本合同只改变输入排队语义，不改变任何模式已有的动画时长、缓动、几何、光影和单页提交阈值。

## 2. 动态净目标

- 状态只保存一个有符号整数 `pendingDelta`，不保存页面对象、动画数组或分页任务队列。
- 下一页输入使目标 `+1`，上一页输入使目标 `-1`；反向输入先抵消尚未完成的净目标。
- `pendingDelta` 包含当前已准入但尚未跨过完成屏障的一页。每跨过一次完成屏障，只消费对应方向的一个单位。
- 产品层没有 16 页或其他固定总页数上限。只要书籍边界尚未到达且用户继续输入，目标就可以继续增长。
- 任一时刻最多只有一个视觉动画和一个对应的 Core/进度事务。下一页只能在当前页完成或明确回滚后开始。

## 3. 完成屏障

- 仿真、覆盖、滑动：动画到达终点、目标页提升为当前页且进度提交完成后消费一页。
- 无动画及跨章节测量：目标页成为可见页并完成首次进度提交后消费一页。
- 滚动：一次 `scrollPage` 停止并完成该次可见位置提交尝试后消费一页；如存在尾随合并提交，后续目标等待提交通道释放。
- 回滚或提交失败不消费目标。单个页面事务最多重试 3 次；达到上限后清空本轮目标以避免故障自旋。该限制不是连续翻页总量上限。

## 4. 输入所有权与优先级

- 当前结算不可被中途打断；结算期间只解析一个完整指针段，多指不得替换首指所有权。
- 结算期间产生的方向输入更新动态净目标，当前动画结束后自动继续。
- 中心控制请求优先于尚未执行的方向目标；已开始且不可中断的一页先完成，随后清空其余目标并打开控制层。
- 控制层、全屏遮罩、显式章节跳转、布局/来源切换、退出和生命周期失效会取消本轮快速翻页目标。
- 快速翻页目标未清空前，文本选择不具备页面主体的稳定输入所有权。

## 5. 边界与跨章节

- 页内目标通过现有前页/当前页/后页三页窗口串行准备，不扩张为 N 页纹理或 N 页分页缓存。
- 到达章节边界时沿用现有章节测量与提交链，保留动态目标；目标可从第 16 页继续到第 17 页及后续章节。
- 到达全书开头或结尾时，只清除指向不可达方向的剩余目标。反向净目标继续有效。

## 6. 验证门槛

- 纯状态测试至少覆盖 1000 次同向输入、反向抵消、控制层优先、边界、失败重试和生命周期取消。
- 源码合同测试覆盖五种模式共享入口、单事务串行、三页窗口和所有完成/回滚钩子。
- 构建通过后在 VM 验证五种模式的连续点击、反向抵消、跨章节、控制层接管和文本选择关闭。
- VM 只能证明功能链路；仿真跟手感、帧率和真机输入节奏仍须真机证据及用户验收。
