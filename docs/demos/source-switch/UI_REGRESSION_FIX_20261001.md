## 原因与修复

原空库书架使用独立位图标题及默认居中的 Scroll，历史修复只覆盖非空书架；分支又没有带入主工作区的五项旧修复及其专项。因此旧检查全部通过，仍不能覆盖空库或分支未保留的历史修复。完整历史及先红证据见 [审计](UI_REGRESSION_AUDIT_20261001.md)。

| 问题 | 实际修复与边界 |
|---|---|
| 空库标题模糊、位置偏移、内容空隙 | 书架各状态共用一个 BookshelfShell/AppTopBar/MainTabShell，空态正文顶部对齐 |
| 加载/首次失败绕过书架顶栏和导航 | 同一壳的内容 slot 显示加载、空库、列表、失败重试；SDK 保留壳回放覆盖四态 |
| 返回栏标题、设置图标主题冻结 | 窄迁已有主题实时取值修复，保留节点日/夜/日回归 |
| 翻页标题、驻留窗口错误章首、末尾空行 | 窄迁标题与正文同一 fragments owner、窗口起点判定、逻辑末尾换行排除；不改 Native/Core |
| 短目录详情下移、设置页私有顶栏 | 详情明确顶部对齐；设置复用 PageBackBar 与正文滚动，保留原持久化方法 |
