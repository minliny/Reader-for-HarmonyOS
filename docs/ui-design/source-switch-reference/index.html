安全边距

点击画布控制栏中的“换源”，也可以自动播放全过程。

  1. 控制栏从阅读入口点击换源
  2. 换源抽屉展开书籍摘要和书源列表
  3. 成功书源增量加入检查成功后才进入列表
  4. 换源动画选择书源并衔接阅读位置
  5. 恢复阅读显示新书源并继续当前章节
已进入阅读控制栏，点击“换源”开始。

使用选定稿的模拟书源与阅读内容；布局、字体和动画来自共同规格。定位章节开头文案与当前业务一致。源码校验不代表浏览器或VM视觉验收。
