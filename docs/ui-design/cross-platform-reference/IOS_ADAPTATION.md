# iOS 复刻适配与交付边界

本文件收敛已选定的全平台兼容样式及其 iOS 适配依据，不改变产品设计。
基准为以下已提交主线组合；正在进行的 HarmonyOS 原生特性分支及未提交改动不属于输入。
这里的“非原生基准”指不采用后续原生风格改造，并不撤销既有文件选择、键盘、系统媒体等 Host 职责。
本文不是 iOS 已实现、已编译或已验收声明。

## 2. 页面与状态映射

iOS 页面应承接相同书籍、来源、章节、任务和操作身份，而不是只复刻入口截图。
SwiftUI/UIKit 的选型不改变 Core 事实、页面状态和用户动作语义；本文不预定框架架构。

| 范围 | 保持的行为 | iOS 适配边界 |
| --- | --- | --- |
| 主入口 | 书架、设置；搜索与阅读由业务入口进入 | 保留应用自绘导航，不因系统默认模板增加 Tab |
| 书架/搜索/详情 | 内容类型、过滤、选择、草稿、滚动及当前书籍上下文 | 原生容器承载既有 UI；返回恢复由对应 owner 管理 |
| 本地导入 | 应用内入口→系统选择→原任务进度与逐项结果 | 文件选择取消与导入取消分开，关闭展示不伪造任务终态 |
| 小说阅读 | 正文、目录、书签、搜索、控制模块与位置锚点 | 重新排版不以旧页码作为唯一位置身份 |
| 漫画阅读 | 图片清单、逻辑页、位置、目录及独立控制面板 | 不套小说 Quick/Full 或听书模块 |
| 换源 | 当前候选、原操作、提交/失败/取消及章首定位合同 | 不增加预览、比较或第二确认页面 |
| 下载/书源管理 | 原任务、原实体、实际可用动作与失败反馈 | 不把触发动作等同于持久化已确认 |
| 关闭表面 | Discover、RSS、Sync、未准入设置保持不可达 | 不按旧规格增加入口或使用空页面占位开放 |

页面加载、已有内容下刷新、确认空、无可用内容失败、原写入未决应分别映射。
组件外观及状态仍按当前对应入口读取；不能将所有失败统一换成全屏错误页。
当前跨页面接线依据见 [interaction-wiring](../../architecture/interaction-wiring-20261019/README.md)。

## 3. 窗口、安全区与键盘

以下是历史移植稿已有原则的明确适用范围，尚未代表 iOS 原生验证结果。
页面专属尺寸取当前基线；历史稿中的固定导航尺寸和页面尺寸不在本文复制。

| 项目 | 适配规则 | 需要记录的输入 |
| --- | --- | --- |
| 单位 | 设计布局 1 vp 对应 1 iOS 逻辑 pt；字体基准 fp 对应 pt 后再应用其缩放 owner | 窗口逻辑尺寸、显示密度、系统字号 |
| 窗口 | 使用当前应用窗口的 W/H，不按整屏型号或整张 390 稿同比缩放 | 分屏、横竖屏及窗口变化 |
| 安全区 | S 为运行时 inset；普通页内容避让，背景可铺满；同一 inset 只消费一次 | 四边 inset 及由谁消费 |
| 横向 | 原边距与 S.left/right 按原布局合并，不无条件重复相加 | 页面边距与横向 inset |
| 底部 | 浮动导航/操作条按当前几何与底部安全区定位；列表末项必须可见可操作 | 底栏实测高度、内容尾部预算 |
| 键盘 | K 为实际遮挡；编辑区域参考 `H-max(S.bottom,K)`；浮动键盘按遮挡矩形处理 | 键盘 frame、输入焦点、滚动恢复点 |
| 阅读 | 背景/图片与正文/元信息/命中区分别计算；全屏变化重新测量并保留锚点 | 阅读几何、系统栏状态与位置锚点 |
| 系统栏 | 应用自绘顶栏不叠加默认导航栏；系统栏颜色随当前纸色/主题适配 | 可见性、对比度及正文避让范围 |

历史稿给出的 iOS 安全区数字只是压力样本，不能写成设备常量。
历史稿曾为搜索提出 W≥600 的跨平台宽度策略；当前各页面是否统一使用该策略见 `IOS-REF-01`。
阅读信息栏的 HarmonyOS 光学校准系数不能直接作为 iOS 系统时间字形定位公式，见 `IOS-REF-02`。

## 4. 字体、颜色、图标与文字布局

颜色消费 [Reader-UI/theme/registry.json](../../../../Reader-UI/theme/registry.json) 的语义角色。
阅读主题与应用主题保持原有独立选择语义，不能由系统 dark mode 覆盖已保存配置。
字族、字重、字号与显式行高以 [ReaderTypography](../../../entry/src/main/ets/features/common/ReaderTypography.ets) 和对应页面角色为准。
换源组件使用共同视觉规格声明的物理字体资产；其他页面按各自已登记来源解析。

| 项目 | 已有移植原则 | 交付边界 |
| --- | --- | --- |
| 字体文件 | 使用声明的真实文件、字重和许可；不把可变字体与静态字体默认视为字形等价 | 记录文件身份；替代文件须单独说明 |
| 系统文字缩放 | 历史稿采用 UIFontMetrics 角色映射：首页/页面 title1/title2、区段 headline、Tab/元信息 caption1、其余 body | 具体角色与当前 Typography 对照，缺项标 gap |
| 阅读正文缩放 | 已保存 appearance 字号/行距拥有正文排版，不再叠乘一次系统字号 | 校验位置锚点与重新分页 |
| 行高 | 显式 lineHeight 与字号分别传入；AUTO 保持平台测量，不猜测 fontSize×常数 | 记录实测行框及溢出 |
| 字体回退 | Inter 的 CJK 回退 Noto Sans SC；Noto Serif 缺字按已有回退原则处理 | HarmonyOS Sans 槽需要 iOS 对应字体校准 |
| 换行 | 保留字段的单行省略、多行上限、硬换行与正文语义；复用平台塑形/断行 | 不用插空格伪造缩进或布局 |
| 大字体 | 行/按钮/说明按实测内容适配；动作与错误可操作，长书名按原约束省略 | 历史移植原则，不声称所有 Harmony 页面已验证 |
| 图标 | 使用登记 SVG/主题变体，保留 viewBox 比例、outline/filled 状态与视觉尺寸 | 不以 SF Symbols 自动替代当前设计资产 |

字体回退、字形、基线、阴影与抗锯齿差异须逐项记录；同样字号并不证明相同排版。
旧稿“≤1逻辑单位”不是本文新设的全应用通过线；误差预算需随具体参考和验收方案确认。

## 5. 手势、动效及返回

动效状态、轨迹参数和实际时长来自本基线的生产 owner 与公共参数；iOS API 只负责执行。
不能用默认 sheet、默认导航转场或一个固定 duration 替代已定义的交互状态机。
主要入口为 [ProductMotionTiming](../../../entry/src/main/ets/features/common/ProductMotionTiming.ts)、
[MotionSpec](../../../entry/src/main/ets/features/common/MotionSpec.ets)、
[ReaderControlMotionPolicy](../../../entry/src/main/ets/features/reading/ReaderControlMotionPolicy.ts) 及对应几何/会话模块。

| 行为 | 跨平台必须保留的语义 | 不得由实现便利推导的规则 |
| --- | --- | --- |
| 按压 | down、up、cancel、禁用状态恢复；沿用 ReaderPressFeedback 的颜色反馈 | 不擅加缩放、波纹或额外触觉 |
| 命中区 | 历史移植稿提出 iOS 最小 44×44；视觉图标尺寸保持，邻近命中区不重叠 | 不能放大图标来代替命中区适配 |
| Quick/Full | pointer 驱动原进度；释放从当前进度续接；重抓/取消保留当前状态 | 不用重新挂载两套树造成回跳 |
| 连续操作 | 原 identity/generation、取消与旧回调隔离 | 旧动画完成不能关闭新层或提交新实体 |
| 阅读返回 | 按当前临时层、Full/Quick、控制首页、正文的消费关系处理 | 不把所有忙态一律禁止返回 |
| 交互式返回 | 提交前不产生业务结果；取消恢复同一页面上下文 | iOS 边缘返回与阅读横向手势优先级见 `IOS-REF-03` |
| 漫画章末 | 向上越界拉动，距离不足回弹，达阈值在释放后进入下一章 | 不改成拖动途中切章，不复活旧准备卡/上一章下拉 |
| 减少动态效果 | 已存偏好与系统设置的映射沿历史移植原则；去掉非必要运动 | 不跳过真实计时、业务回执、取消或恢复 |

漫画章末依据 [当前行为更正](../../MANGA_BOUNDARY_TURN_UI_CONTRACT_20261008.md) 和本基线生产实现。
原生滚动惯性、系统键盘和系统弹窗曲线若未在共享设计中定义，记录 `REFERENCE_GAP`。
不能把 HarmonyOS 内部默认曲线猜成固定参数，也不能把浏览器直接落终态当 iOS 动效完成。
旧稿“时长偏差≤一帧”不自动成为所有设备与系统动画的验收门槛。

## 6. 消息、系统界面与权限

消息复刻先保持 [FRAMEWORK](../../message-ui/FRAMEWORK.md) 的事实分类及 owner，再映射已选定的兼容视觉。
普通短反馈、原操作未决、局部/页面状态、确认、持续任务和阅读专用反馈不得互相替代。
文档中的 HarmonyOS 系统 API 名称只标识适配边界，不能证明 iOS 应采用相同系统几何。

| 平台表面 | iOS 承接的意图与结果 | 当前边界 |
| --- | --- | --- |
| 文件选择/保存 | 用户选择、取消、失败、沙箱授权、暂存及原包生命周期 | 按 [文件合同](../../../../Reader-Core/docs/host-app-contracts/04-local-book-files.md)；不新增格式或解析器 |
| 键盘/输入法 | 输入类型、composition、焦点与遮挡恢复 | composition 中不提交半成品；输入细节逐字段对照 |
| 确认/警告 | 动作、文案、危险性、取消与 owner guard | 既有自绘 Dialog 不自动换成系统 Alert；未定映射见 `IOS-REF-04` |
| 短反馈 | 当前宿主有效、去重、前后台准入及实际业务结果 | 无 iOS 系统 Toast 对等实现证明，视觉载体见 `IOS-REF-04` |
| 登录 Web 容器 | 原书源/会话、登录结果、取消与凭据边界 | iOS 登录/凭据实现及完整合同见 `IOS-REF-05` |
| 权限请求 | 仅由真实 Host 操作发起；拒绝/取消返回原操作上下文 | 不根据 Harmony 权限名称制造 iOS 权限请求 |
| 亮度/系统栏 | 当前用户意图及退出/失焦恢复语义 | 可用 API、恢复时点和权限差异需平台核验 |

关闭提示不是取消任务，读取成功不是原写入已确认，展示失败不能逆转已完成业务。
系统 UI 外观由目标平台适配的场景与自绘兼容样式场景必须逐项登记，不能全局替换。

## 7. 数据、媒体与生命周期

Core 继续拥有书籍/目录/正文、进度、事务与持久化；iOS 不建立第二份业务数据库或通用解析器。
Host 拥有文件、HTTP、Cookie/WebView、音频会话、系统媒体、窗口与绘制资源。
UI 只展示投影并提交意图；草稿、选中项、滚动及动画进度由原页面/会话 owner 持有。

| 事件 | 必须保留的合同 | 尚待 iOS 确定 |
| --- | --- | --- |
| 旋转/分屏/键盘变化 | 不重派导入、删除、换源；重排保留锚点与原操作身份 | 各页布局和焦点迁移 |
| 前后台切换 | 旧回调不能操作新页面；后台不弹应用内短反馈 | scene/runtime 寿命、取消及恢复边界 |
| TTS 播放/暂停/停止 | Core typed queue snapshot 与 Host 系统发声状态分别处理 | 系统语音、音频路由、打断与恢复策略 |
| 锁屏媒体/后台发声 | 消费同一 active session 的意图与事实 | 后台模式、系统媒体命令及退出清理 |
| 持久化未确认 | 保留原请求/operation 身份，核对或继续原操作 | App 被系统终止后的恢复衔接 |

TTS 依据 [Core/Host TTS 合同](../../../../Reader-Core/docs/host-app-contracts/05-tts.md)；
其系统发声、音频会话和设备证据归 Host，不能由 Core queue 通过推导 iOS 媒体完成。
[iOS binding](../../../../Reader-Core/bindings/ios/README.md) 是接入资产，未提供应用界面；
[STATUS](../../../../Reader-Core/bindings/ios/STATUS.md) 的历史 smoke 不覆盖 iOS App/模拟器/真机及后台生命周期。

## 9. 逐状态交付记录

每个实际可达页面/组件记录：route、实体/操作身份、前置条件、事件、目标状态、返回、清理及来源。
只记录适用状态；未知或未触发状态保持未验证，不用样例数代替覆盖。

| 维度 | 最小记录内容 |
| --- | --- |
| 状态 | 初始/有内容、加载、确认空、失败、重试、取消、写入未决与恢复 |
| 导航 | 入口、返回来源、交互返回取消、草稿/滚动/选择恢复 |
| 视觉 | 主题、字体文件、窗口/inset、系统字号、同一内容夹具与参考来源 |
| 动效 | 起止与中间进度、反向/重抓/取消、重复操作、减少动态效果 |
| 生命周期 | 离页、前后台、旋转/键盘、迟到结果与原 owner 退役 |
| 可访问性 | 标签、值、禁用/选中、装饰图标忽略、焦点进入与恢复 |
| 数据 | 原操作真实回执、读回/写入分离、持久位置与失败保留 |
| 证据身份 | 三仓基线、iOS commit/dirty、OS/设备、输入条件、截图/录屏/日志 |

记录分别区分：参考可用、代码接入、本地检查、iOS 构建、模拟器、真机、用户验收。
本次收敛仅产生参考文档；不触发构建、全量门禁、设备测试或应用数据修改。
