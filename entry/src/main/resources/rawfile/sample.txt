Host 本地导入自检样章

这是一段为 Reader for HarmonyOS host 后端自检编写的原创文本。
它只用于验证 rawfile 读取、UTF-8 解码、files:// 写入回读，以及
persistence 元数据落盘，不代表任何线上书源内容。

第一节：导入

应用启动后，自检流程会从 rawfile 中读取这份文本，将它写入
files://local_book/sample.txt，再立即读回并比较内容长度与文本内容。
如果回读内容完全一致，说明本地 TXT 导入链路的文件适配层可以工作。

第二节：元数据

随后，自检会写入一份极小的元数据记录，包含标题、作者、格式和字符数。
这一步验证 Host persistence 能保存本地书籍索引所需的最小字段。

第三节：边界

本文不测试排版、分页、章节切分或阅读器渲染。那些能力属于 Core 与 UI
后续链路。当前样本只证明 host 侧文件与持久化接口能够组成可复用基线。
